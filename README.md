# Video Event Logger

動画の開始・終了時刻の記録と、動画上の2点による傾斜測定を行うPythonアプリです。2つの機能を同じリポジトリで管理します。

## 起動

Python 3.13で `python -m pip install -r requirements.txt` を実行し、`python video_event_logger.py` で起動します。

詳細は README.txt を参照してください。README.txtに記載のvendorと動画は、このリポジトリには含めていません。上記の方法でライブラリをインストールしてください。

自動保存された計測記録、動画、診断結果は登録対象外です。
