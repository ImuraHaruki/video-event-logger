Video Event Logger — Python版

使い方
1. ZIPの場合はフォルダー全体を展開してください。
2. 「起動.cmd」をダブルクリックします。
3. 「動画を開く」でGX010214_timestamp_JST.mp4などを選択します。
4. 速度の数値を入力し「倍を適用」を押します（0.01〜8倍）。
   0.01倍・0.1倍・0.25倍・0.5倍・1倍・2倍のボタンでも即座に設定できます。
   動画画面の右上に適用済みの倍率と再生／一時停止の状態を表示します。
   入力欄を編集しただけでは表示は変わらず、「倍を適用」で更新されます。
5. 現象が始まった位置で「開始を記録」、終わった位置で「終了を記録」。
   同じ動画で何区間でも記録できます。
6. 次の動画を「動画を開く」で選んでも、それまでの記録は一覧に残ります。
7. CSVやJSONで、全動画の記録をまとめて書き出せます。
   各記録には動画名と動画ファイルの場所が入ります。

操作
・動画画面上のホイール：ポインター付近を中心に拡大／縮小（全体表示〜16倍）
・拡大中の左ドラッグ：表示位置を移動
・「表示をリセット」または動画画面のダブルクリック：全体表示に戻る
・画面右上の「表示 ○%」は画面の拡大率です。再生速度・記録時刻は変わりません。
・Space：再生／一時停止
・「最初に戻る」：動画の先頭へ移動して一時停止
・←／→：1秒移動
・Shift＋←／→：1フレーム相当の移動（シークは指定時刻以降のフレーム）
・スライダー：再生位置を変更して一時停止
・記録一覧をダブルクリック：その動画を開いて区間の開始位置へ移動
  動画が移動・削除されている場合は、その動画を選択する画面を表示します。

記録
・表示中のフレームの時刻を記録します。単位は動画先頭からの秒です。
・映像内に焼き込まれたJSTの時計を自動読取する機能はありません。
・全動画の確定した記録は、アプリと同じフォルダーの「records_autosave.json」に
  自動保存し、次回起動時に一覧を復元します。動画ごとに時刻は0秒から数えます。
・旧版の「動画名.mp4.events.json」は、その動画を初めて開くと一覧に取り込みます。
  同じ動画を開き直しても重複取り込みはしません。
・「JSONを保存」は一覧全体の保存、「JSONを読込」は一覧全体の置き換えです。
  旧版のJSONも読み込めます。動画名のない旧記録は対象動画を先に開いてください。
・別フォルダーにある同名動画はファイルの場所で区別します。
・傾斜の記録と動画ごとの長さの基準も同じJSONに保存・復元します。
・アプリを更新する際は、既存のrecords_autosave.jsonを新しいアプリのフォルダーへ
  コピーするか、更新前にJSONを保存して更新後に読み込んでください。
・書込不可の場所では警告が表示されます。JSONを保存で別の場所へ保存してください。
・映像観察用のため音声は再生しません。
・高倍率でPCの処理が追いつかない場合は表示フレームを間引きます。
  動画内時刻に基づく再生速度を保ちます。

傾斜の測定
1. 動画を開いて測定する位置へ移動し、「傾斜を測定・記録」を押します。
2. 既知の長さと単位（cm、mなど）を入力し「基準2点を指定」を押します。
   動画画面で、その長さに対応する2地点をクリックしてください（水色のC1・C2）。
3. 「傾斜2点を指定」を押し、傾斜を測る2地点をクリックします（黄色のP1・P2）。
4. 結果を確認して「傾斜を記録」を押します。メモはメイン画面の現象名・メモ欄です。
5. 位置や動画を変えて繰り返せます。「全動画の傾斜CSVを書き出す」で一括出力します。
   「全記録JSONを保存」は区間記録・傾斜記録・長さの基準をすべて保存します。

・画像の横方向を水平として、右上がりが正・右下がりが負の角度です。
  角度は度、勾配は高さの差／水平距離×100（%）。垂直線の勾配は空欄です。
・点を指定し始めると表示フレームを固定します。再生または位置移動で指定を終了します。
・点指定中もホイールで拡大でき、右ドラッグで表示位置を動かせます。
・基準線と測定線は元画像のピクセル座標で保存し、ズーム倍率の影響を受けません。
・新しい動画には直前の基準点・既知の長さ・単位を自動で引き継ぎます。
  その動画に設定済みの基準がある場合は、その基準を優先します。再起動後も引き継ぎます。
  同じ縦横比で解像度だけが異なる場合は、基準点の座標を解像度に合わせて換算します。
  縦横比が異なる場合やカメラの位置・向き・ズームが変わった場合は再指定してください。
・画像上の傾斜・長さです。基準線と測定線が同じ平面にあり、縦横の縮尺が等しいことを
  前提とします。遠近やレンズ歪みは補正しません。画像の横方向と実際の水平も一致させてください。
・CSVには動画名・場所・動画内時刻・角度・勾配・水平距離・高さの差・線の長さ・単位・
  測定点と基準点の元画像座標・既知の長さを出力します。

必要環境
・Windows 64bit、Python 3.13（このPCの既存環境で検証済み）
・vendorにPyAVとPillowを同梱しています。インターネット接続は不要です。
・このPCのPython環境で実動作を検証しました。
・同梱PillowはPython 3.13用です。別のPython版（3.12以上）で使用する場合や、
  ライブラリの読込エラーが出る場合は、vendorフォルダーを別名にし、
  コマンドプロンプトで次を実行してください。
    python -m pip install -r requirements.txt
    python video_event_logger.py
